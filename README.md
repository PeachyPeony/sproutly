# Sproutly 
A cheerful to-do list app built with React and the Context API.
Sproutly helps you keep track of everyday tasks, one task at a time. 
Add tasks, mark them as complete, and celebrate the little wins along the way.

## Features
- Add new tasks
- Mark tasks as complete or incomplete
- Delete tasks
- View the total number of tasks, including completed tasks
- Responsive layout for different screen sizes

## Built With
- React
- JavaScript
- HTML5
- CSS3
- React Context API
- Vite
